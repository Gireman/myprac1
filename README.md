# Crema — сайт с рецептами кофе

Crema — сайт созданный во время учебной практики: каталог рецептов приготовления кофе с понятными пропорциями, шагами и советами по оборудованию.

## Что умеет сайт

- Каталог рецептов с фильтром по способу заваривания (пуровер, аэропресс, эспрессо, капучино и др.)
- Страница рецепта: сколько кофе и воды нужно, время приготовления, шаги, нужное оборудование, вкусовой профиль
- «Подобрать по вкусу» — короткий опрос (настроение, как пьёте кофе, сколько времени есть), после которого сайт предлагает подходящий рецепт
- Регистрация и вход пользователей
- Избранное — можно сохранять понравившиеся рецепты
- Админ-панель — добавление, редактирование и удаление рецептов и пользователей

## На чём сделано

- **PHP** и фреймворк **Yii2** — основа сайта
- **MySQL** — база данных (рецепты, пользователи, избранное, оборудование)
- **HTML, CSS и JavaScript** — внешний вид и интерактив
- Картинки в современном формате WebP разных размеров, чтобы страницы грузились быстрее

## Структура проекта

- `controllers/` — логика страниц
- `models/` — работа с данными (рецепты, пользователи, избранное)
- `views/` — шаблоны страниц
- `migrations/` — создание таблиц в базе
- `web/` — стили, скрипты, картинки
- `config/` — настройки
